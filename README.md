# 난초 (NANCHO) — THE MIDNIGHT LOG

자정에만 잡히는 주파수를 받아적는 기록실. 바닐라 HTML/CSS/JS + Supabase + Cloudflare Pages.

## 1. 배포 순서 (처음 한 번)

### ① Supabase — SQL 한 번 돌리기
프로젝트(`wtwibpchtbjwiuvzaybh`)는 이미 연결돼 있습니다. **표(테이블) 만들기만 하면 끝:**
1. Supabase 대시보드 → 왼쪽 **SQL Editor** → **New query**
2. `supabase_setup.sql` 파일 내용을 **전부** 붙여넣고 **Run**
   - 테이블·권한·난초 기본값이 한 번에 들어갑니다.
   - 여러 번 실행해도 안전합니다(기존 편집 내용을 지우지 않음).

### ② `supabase.js` — ✅ 이미 채워져 있습니다
프로젝트 `wtwibpchtbjwiuvzaybh` 기준으로 주소·키가 들어가 있어 따로 손댈 게 없습니다.
나중에 프로젝트를 옮기면 이 파일 상단 두 줄만 바꾸면 됩니다.
```js
const SUPABASE_URL  = 'https://wtwibpchtbjwiuvzaybh.supabase.co';
const SUPABASE_ANON = 'eyJhbGciOi...';
```
> anon 키는 원래 브라우저에 공개되는 키라 소스에 있어도 괜찮습니다. 다만 **service_role 키는 절대 넣지 마세요.**

### ③ 관리자 비밀번호 바꾸기
`admin/index.html` 안에서 검색:
```js
var ADMIN_PW = '1234';
```
**반드시 배포 전에 다른 값으로.** 소스에 그대로 보이니 다른 곳에서 쓰는 비번은 쓰지 마세요.

### ④ GitHub 업로드
아래 구조를 **그대로** 올립니다. (`fx.js`·`site.js`·`style.css`·`supabase.js`는 루트)
```
index.html  style.css  fx.js  site.js  supabase.js  supabase_setup.sql
assets/                       ← 배경 이미지 6장 (webp)
admin/index.html              ← 관리자
overlay/index.html            ← OBS 오버레이
profile/  notice/  schedule/  work/  diary/  song/  dress/  game/   (각 index.html)
.github/workflows/keepalive.yml
```

### ⑤ Cloudflare Pages 연결
**Workers & Pages → Create → Pages → Connect to Git** → 저장소 선택 →
- Framework preset: **None**
- Build command: **비움**
- Output directory: **비움 (또는 `/`)**
→ **Save and Deploy**. 1~2분 뒤 `https://xxxx.pages.dev` 로 열립니다.

### ⑥ Supabase 슬립 방지 (선택이지만 권장)
GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret**
- `SUPABASE_URL` · `SUPABASE_ANON_KEY` 등록
→ 매주 월·목에 자동으로 한 번 찔러 프로젝트가 잠들지 않습니다.

### ⑦ SOOP 게시글에 넣기
SOOP 글쓰기에서 HTML 모드로:
```html
<iframe height="2400" scrolling="no" src="https://xxxx.pages.dev" style="width:100%;border:0;display:block;"></iframe>
```
높이는 **픽셀**로 지정하세요(%는 안 됨). 페이지가 자체적으로 높이를 부모에 알려주므로 대략만 맞춰도 됩니다.

## 3. 관리자 사용법 — `/admin`

비번 입력 후 탭 10개.

| 탭 | 하는 일 |
|---|---|
| 🏠 메인 | 프사, 이름/읽기, 캐치프레이즈, 소개 한 줄, 메인 문구·일러, 링크 4종 |
| 🎀 프로필 | 기본 기록(나이·데뷔·생일·소속 등), About, 능력치, 마일스톤, 좋아/싫어, TMI, 채팅 규칙 |
| 📢 공지 | 공지 등록/삭제, 고정(📌) 토글, 이미지 주소 |
| 📅 일정 | 날짜·1부/2부 시간·제목·종류(색)·굵게 표시 |

**요일별 편성(메인 주간 칸)** — 🏠메인 탭 아래쪽 「요일별 편성」에 `내용|시간` 형식으로 넣으면 시안처럼 요일마다 다르게 표시됩니다.
예: 월 `CHAT|21:00`, 화 `GAME|22:00`, 수 `비움`(휴방), 목 `TALK|21:00` …
한 칸이라도 채우면 위의 요일 체크박스 대신 이 표가 우선하고, 전부 비우면 체크박스 방식으로 돌아갑니다.
| ⚡ 업보 | 시청자·업보 종류 등록 → 표에서 숫자만 입력하고 저장 |
| 📓 일기 | 제목·본문·이미지, 댓글은 사이트에서 초단들이 남김 |
| 🎵 노래·VOD | 곡 개별 추가 / 벌크 추가(`제목 - 아티스트 - 장르` 한 줄씩), VOD는 **ID 숫자만** |
| 👗 옷장 | 이미지 주소·제목·분류(헤어/의상/렌즈/이벤트)·NEW 배지·정렬순서 |
| ✉️ 문의 | 사이트 문의 모달로 들어온 글 확인/삭제 |
| 🎨 테마 | 프리셋 5종 · 색 6종 팔레트 · 대비 진단 → 저장하면 전 페이지에 자동 적용 |

### 관리자 편의 기능
- **👁 이 탭 페이지 미리보기** — 지금 보고 있는 탭에 해당하는 페이지를 새 창으로 엽니다.
- **💾 백업 / 📂 복원** — 프로필·문구·색 전체를 `.json` 파일로 내려받고, 나중에 그대로 되돌릴 수 있습니다. 색을 크게 바꾸기 전에 한 번 눌러두면 안전합니다.
- **● 저장하지 않은 변경이 있어요** — 저장 전에 창을 닫으려 하면 경고합니다.
- **이미지 미리보기** — 이미지 주소 칸에 붙여넣으면 바로 아래에 그림이 뜹니다. 안 뜨면 주소가 잘못된 것(글 주소를 넣었거나 원본이 삭제됨).
- **🎨 프리셋** — 미드나잇(기본) / 체리 나이트 / 피치 워터 / 딥 오션 / 모노 실버. 누르면 6색이 한 번에 채워지고, 거기서 원하는 색만 손보면 됩니다.
- **대비 진단** — 색을 고를 때마다 "읽히는지"를 수치로 보여줍니다. **4.5:1 이상**이면 안전, `안 읽힘`이 뜨면 그 색은 피하세요.

**저장 후 사이트에서 안 보이면** → 캐시입니다. Ctrl+Shift+R.

### 배경·대표 이미지 바꾸기 (🏠 메인 탭)
- **🌙 밤 배경 / ☀️ 낮 배경** — 전 페이지 공통 배경. 가로 16:9(1920×1080 권장).
- **메인 히어로 사진** — 메인 첫 화면 사진. 인물이 **오른쪽**에 오는 구도가 가장 잘 맞습니다(왼쪽에 이름·문구가 얹힘).
- 레포에 올린 파일이면 `/assets/파일명.webp` 처럼 `/` 로 시작하게 적으세요.
- 비우면 기본 이미지가 그대로 쓰입니다.

### 프사 넣는 법
- **SOOP 아이디만** 입력하면(`blackchu`) 방송국 프사가 자동으로 붙습니다.
- 움짤이나 다른 이미지를 쓰려면 **직접 이미지 주소** 칸에 넣으면 그게 우선합니다.

### 이미지는 왜 "주소(링크)"로 넣나요?
이 사이트는 **서버가 없는 정적 사이트**라 파일을 받아 보관할 창고가 없습니다. 그래서 사진은 이미 인터넷에 올라가 있는 것을 **주소로 불러옵니다.**
- **용량 걱정 없음** — 사진을 사이트에 쌓지 않으니 무료 DB 용량·전송량 한도에 걸려 사이트가 멈출 일이 없습니다.
- **더 빠름** — SOOP 서버가 이미지를 대신 배달합니다.
- **바꾸기 쉬움** — 주소 한 줄만 갈아끼우면 끝.

⚠️ 대신 **원본 글을 지우면 사이트에서도 사진이 사라집니다.** 올린 글은 그대로 두세요.
(관리자 🏠메인 탭·👗옷장 탭에도 같은 설명이 접이식으로 들어 있습니다.)

### 이미지 규격 정리
| 어디에 쓰이나 | 비율 | 권장 크기 | 참고 |
|---|---|---|---|
| 밤 배경 · 낮 배경 | 가로 16:9 | 1920 × 1080 | 글자가 얹히니 너무 복잡한 그림은 피하기 |
| 메인 히어로 사진 | 가로 16:9 | 1920 × 1080 | 인물이 **오른쪽**에 오는 구도 |
| 프로필 사진(프사) | 정사각 1:1 | 400 × 400 | 움짤(.gif)은 200px 안팎으로 |
| 프로필 대표 일러스트 | 세로 4:5 | 900 × 1125 | 비우면 프사가 대신 들어감 |
| 팬 캐릭터 | 세로 4:5 | 800 × 1000 | 배경 없는 투명 PNG 권장 |
| 옷장 컷 | 세로 3:4 | 900 × 1200 | 비율이 다르면 위아래가 잘림 |
| 공지 · 일기 이미지 | 가로 3:2 안팎 | 1200 × 800 | 너무 긴 세로만 피하기 |

한 장 **1MB 아래**를 권장합니다.

### 이미지 주소 얻는 법 (옷장·공지·일기)
1. SOOP **비공개 게시판**에 글을 쓰고 이미지를 업로드 → 저장
2. 올라간 이미지를 **우클릭 → "이미지 주소 복사"**
3. 주소가 `https://stimg.sooplive.com/...` 처럼 **이미지 파일 주소**여야 합니다 (글 주소 ✗)
4. ⚠️ 원본 글을 지우면 사이트에서도 이미지가 사라집니다.

**옷장 권장 규격: 세로 3:4 (예 900×1200).** 컨택트 시트가 3:4로 자릅니다.

## 4. OBS 오버레이 — `/overlay`

방송 화면에 "지금 트는 노래" 바를 띄웁니다.

1. OBS → 소스 추가 → **브라우저**
2. URL: `https://xxxx.pages.dev/overlay/`
3. 너비 **720** · 높이 **130**
4. 관리자 🎵 탭 맨 아래 **OBS 오버레이** 카드에서 곡·아티스트 입력 후 **표시 ON** → 방송 화면에 슬라이드로 등장, OFF 하면 사라집니다.

## 5. 알아두면 좋은 것

- **다크(밤) / 라이트(주간)** 토글은 상단 `DAY`·`NIGHT` 버튼. 선택은 브라우저에 기억되어 페이지를 옮겨도 유지됩니다.
- 라이트 모드 배경은 지급받은 벚꽃 낮 이미지(`assets/nancho-day.webp`), 다크는 `nancho-purple-night.webp`. 바꾸려면 같은 파일명으로 교체하면 됩니다.
- **떠다니는 장식(플로팅)은 전부 꺼져 있습니다.** 다시 켜려면 `fx.js` 맨 위 `FX_COUNT`를 16 정도로, `FX_TILT`를 `true`로.
- 클릭할 때 튀는 입자 모양은 `fx.js` 맨 위 `FX_CLICK`.
- **방송 요일**은 아무것도 체크하지 않으면 "요일 고정 없음"으로 7칸이 모두 열립니다(난초 기본).
- 페이지를 빼려면 세 곳을 같이 지웁니다: ① 각 페이지 상단 nav ② 해당 폴더 ③ 관리자 탭.

## 6. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 값이 전부 기본값 | `supabase.js` 2줄 미입력 |
| 401 / 저장 실패 | URL과 anon 키가 같은 프로젝트 것인지 |
| 추가하면 404 | `supabase_setup.sql`을 아직 Run 하지 않음 |
| 저장했는데 안 보임 | 캐시 → Ctrl+Shift+R |
| 옷장·공지 이미지 안 뜸 | 글 주소를 넣었거나 원본 글이 지워짐 |
| 며칠 방치 후 안 됨 | Supabase 일시정지 → 대시보드에서 Restore + keep-alive 시크릿 등록 |
