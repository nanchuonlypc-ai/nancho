이미지는 왜 "주소(링크)"로 넣나요? — 꼭 한 번 읽어주세요
이 사이트는 서버가 없는 정적 사이트입니다. 파일을 받아 보관할 창고가 없어요. 그래서 그림은 이미 인터넷 어딘가에 올라가 있는 것을 주소로 불러옵니다.
  • 용량 걱정이 없습니다. 사진을 사이트에 쌓지 않으니 무료 DB 용량·전송량 한도에 걸려 사이트가 멈출 일이 없어요.
  • 더 빠릅니다. SOOP 서버가 이미지를 대신 배달해 주기 때문에 로딩이 가볍습니다.
  • 바꾸기 쉽습니다. 주소 한 줄만 갈아끼우면 끝, 다시 업로드할 필요가 없어요.
어디에 올리면 되나요?
  • SOOP 비공개 게시판에 글을 하나 만들어 사진을 올리고 저장하세요(공개 안 해도 됩니다).
  • 올라간 사진에 마우스 우클릭 → "이미지 주소 복사".
  • 복사한 주소를 아래 칸에 붙여넣으면 바로 미리보기가 뜹니다. 안 뜨면 주소가 잘못된 거예요.
⚠️ 주소는 .jpg / .png / .webp / .gif 로 끝나는 이미지 주소여야 합니다 — 글 주소(…/post/123)는 안 됩니다.
⚠️ 원본 글을 지우면 사이트에서도 사진이 사라집니다. 올린 글은 지우지 말고 그대로 두세요.
